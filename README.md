# 观画 · 摄像头视线估计先导研究

[在线测试网站](https://roibai.github.io/painting-gaze-pilot/) · [GitHub 仓库](https://github.com/RoiBai/painting-gaze-pilot)

本地 React + TypeScript + Vite 网站。默认每个场景观看 **60 秒**（两景共 2 分钟，不含校准与问答）。真实采集只调用官方 **WebGazer 3.5.3**；没有自写视线模型、鼠标替代样本或生产模拟数据。默认试用《明宣宗行乐图》同一长卷的射箭和蹴鞠两个场景，不是两幅独立作品。材料默认待研究者核查，正式模式会拦截未准备好的材料。

## 启动

已在本机安装并锁定依赖。首次或重新解压后：

```bash
cd painting-gaze-pilot
npm ci
npm run dev
```

在桌面 **Chrome** 打开 **http://localhost:5173**。服务只监听本机 127.0.0.1；使用 localhost 地址避免官方库旧的 HTTP 检查提示。不能双击 index.html。测试过 Node 18.19.0 / npm 10.2.3；建议兼容的 Node 环境。停止服务按 Ctrl+C。

```bash
npm test              # 坐标、验证、状态、适配器、CSV、存储等单元测试
npm run build         # TypeScript 检查和静态生产构建
npm run preview       # 构建后 http://localhost:4173
npm run test:e2e      # 本机已安装 Google Chrome；Playwright 自动启停本地服务器
```

`predev` / `prebuild` 自动将官方包内 JS、MediaPipe WASM/model 和许可证原样复制到 public/vendor。安装依赖需要网络。实测自动化 Chrome 中模型资源均从 localhost 加载；**目标电脑真人、断网条件下的完整验证仍未完成**，不宣称已经保证完全离线。

## 最短人工验收（真实摄像头验证待在本机完成）

1. 研究者设置保持「预览」，时长改为 **5 秒**，选 N01；同意后启用真实摄像头。检查模型加载、人脸反馈、系统相机灯。
2. 注视每个圆点并点击 5 次，完成九点校准。独立验证只看圆点，不移动鼠标去追点；检查各目标样本数和误差，不把“有预测”当成准确。
3. 验证结果展开「研究者：真实预测接通检查」。保持鼠标不动，依次看左 / 中 / 右大目标，观察实际库回调 x/y 是否随注视变化。**这是接通检查，不是科学精度证明。** 未设误差标准但样本足够时显示「质量未判定」，可保留此状态继续；实际样本不足或误差超标时会明确提示原因，继续须保留低质量标记。
4. 完成每景前漂移检查、两景短观看、熟悉度、前题、两张固定卡、后题和访谈。观看时应只有原图；按 Esc 暂停会遮住画面。切换标签和调整窗口应触发暂停/重新校准。
5. 结果页下载 ZIP；核对两幅密度图和两幅轨迹图 PNG、四个 CSV、session.json。gaze_samples 应有真实变化的回调；null 留空，画外不夹边。退出后相机灯应熄灭。新选 N02，须重新校准，顺序 BA。

若失败，请保留错误界面、控制台错误、Chrome 版本与网络失败资源。不要改用鼠标或随机样本继续冒充摄像头记录。没有相机也可明确选择「仅试用流程」，会显示无数据，保存 flow_only 标记。

## 材料与设置

- `src/study.ts`：默认 study 配置及完整校验。`src/sceneMaterials.ts`：实际两个场景的图源、关系、AOI、问题、固定卡、评分和访谈。`public/study.example.json` 为可导入示例。
- `public/materials/provenance.json`：图源及裁切记录；[材料说明](docs/MATERIALS.md) 列出待冻结内容。保留来源图，不以旧热图作为刺激，不根据热图编历史解释。
- 开始页「研究者设置」可改时长、AB/BA、模式、回归、库内 Kalman、显示模式和验证阈值，或载入完整 JSON。开始后配置克隆冻结，逐会话导出。
- 正式模式要求两份材料 `verified:true`、`placeholder:false` 且结构完整。**这个标志是研究者完成核查后的声明，不是机器保证历史正确。** 请先核查完整场景、分辨率、来源、题目与评分并冻结材料版本。当前仍设为 false。
- N01/N03/N05 默认 AB，N02/N04/N06 默认 BA；每人看相同固定解释卡。旧 R01–R09 资料只列在完成后的独立研究者参考区。
- 全屏必须在校准前选择。正式观看 contain 完整显示；坐标用实际图像内容矩形计算，CSS px 不乘 DPR。

## 流程、质量与计时规则

同意 → 摄像头 → 九点校准 → 独立验证 → 研究者判定 → 三点漂移检查 → 第一景自由观看 → 熟悉度 → 前题 → 固定两卡 → 后题 → 第二景同流程 → 访谈 → 结果。

验证默认每目标 2500ms，前 700ms 为稳定期。暂定合格线为：每目标至少 10 个有效样本；整体中位误差不超过 250 CSS px 且不超过视口对角线的 10%；每个目标的中位误差均不超过 200 CSS px。四项同时满足才通过。此为粗区域先导采集的项目筛选线，不是公认精度标准；详见 [合格线说明](docs/QUALITY_POLICY.md)。误差为预测至目标的欧氏距离（CSS px）；整体是全部有效验证样本误差的中位数，相对误差为每样本误差/视口对角线的中位数。任一目标不足即失败；所有误差阈值均未设置时为待判断；有标准时所有已设置标准都需符合。目标和阈值均可在 JSON 配置中调整，正式采集前冻结。独立验证不调用训练 API。

每次重校准递增 calibrationVersion。窗口变化、相机故障要求重新校准；标签隐藏/失焦/手动 Esc 暂停并遮画。短 null 保留；自由观看连续无预测超过默认 3000ms 暂停。恢复需要窗口回到前台和近期真实预测，或显式改成 flow_only。验证中途暂停后重启新的验证 run，旧 run 保留。答题时窗口变化也会使下一景前强制重校准。

图片 decode 完成并经过浏览器帧回调后才进入自由观看；这不是硬件呈现或曝光同步。`performance.now()` 记录本页单调时间，另保存 timeOrigin 和 UTC。100ms 计时调度检查阶段结束；实际 wallMs 记录检查时刻，activeMs 记录实际展示累计，在退出/暂停时封口。自由观看中重校准会保留中断段，创建新 trialId 重复整段并标记低质量/重复曝光；回看汇总所有真实曝光，不暗删数据。

## 分享给参与者（GitHub Pages）

网站可部署到 GitHub Pages 的 HTTPS 地址。参与者用电脑 Chrome 普通窗口打开，选择研究者分配的 N01–N06 编号并允许摄像头。完成后点击「一键导出全部数据 ZIP」，在下载文件夹找到 ZIP 并通过约定的方式自行发回研究者。网页不会自动发送数据。

在网站链接后添加 `?participant=N01` 至 `?participant=N06` 可预选编号；奇数编号默认 AB，偶数 BA。浏览器和设备各自保存记录，研究者无法通过链接看到其他人的数据。同一台电脑也可以从「本机已保存的会话」重新打开结果、再次下载。不要使用无痕窗口或清除网站数据；本地 localhost 与线上地址的记录相互独立。

每个 ZIP 包含全部原始视线回调（含 null）、验证/校准记录、流程事件、回答、配置及质量摘要，以及两幅密度图和两幅轨迹图。没有摄像头视频或眼部照片。默认仍为测试/预览模式，质量与材料核查标记不会因上线而变成通过。

部署和更新步骤见 [GitHub Pages 部署说明](docs/DEPLOYMENT.md)。

## 保存、回看、导出

研究数据库 `painting-pilot-study-v1` 与 WebGazer 默认 localforage 分开。每秒及阶段切换写入 IndexedDB，128 行分块事务。浏览器崩溃可能损失最后一次成功批次后的记录，**最多约一个保存间隔并非保证**。刷新后读取已存数据、将 active 会话/试次标 interrupted，不把重启当成原连续采集；返回开始页新建并重新校准，原记录保留。不要使用无痕窗口或清除网站数据；每人结束后下载 ZIP。

导出含 `gaze_samples.csv`、`phase_events.csv`、`responses.csv`、`validation.csv`、`session.json`、两个热图 PNG 和两个 Scan path 估计轨迹 PNG。单文件名及 ZIP 根目录含模式、参与者和唯一会话 ID。CSV 为 UTF-8 BOM、RFC4180 引号/换行；null 为空。为保留原话不改写以 `=` 开始的文本；分析时请以文本导入 CSV。配置含图片相对路径，因此长期复现应一并保留本项目对应材料版本。

密度图只用本会话 free_view、非暂停、有限且在画内的真实预测。每样本权重 1，不识别 fixations/saccades。高斯核参数、尺寸、逐图最大值归一化、颜色与筛选规则写入 JSON。零数据不生成热点。参数相同可从 JSON 重建相同 PNG；[导出与数据说明](docs/DATA_AND_EXPORT.md) 提供细节。

## Scan path 估计轨迹

完成或结束会话后，在结果页选择「Scan path · 估计轨迹」。支持播放/暂停、速度切换、时间拖动、最近5秒或完整轨迹、编号密度和显示间隔。已有历史会话也能用保存的 gaze_samples 生成，无需重采。时间从该画首次展示起计算，包含暂停和重复曝光间隔。

轨迹先按原有数据检查连续性；null、画外、暂停、超过250ms的回调缺口、阶段/试次/校准/几何变化均断线，再作显示抽稀。默认约200ms选一个**实际样本**，不平均、不补点、不改CSV。圆点大小固定，编号表示显示样本的时间顺序，不是注视事件编号。线只表示有序估计轨迹，不宣称经过线上的每一位置。

单独轨迹PNG和一键ZIP均导出**完整时段**（不含AOI框），同时在session.json保存轨迹参数与绘制范围；回放窗口不改变完整导出。详见 [轨迹说明](docs/SCANPATH.md)。
