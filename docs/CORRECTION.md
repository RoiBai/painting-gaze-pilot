# 事后参考偏移校正

此功能提供从已保存检查点估算的**派生参考图**，不宣称恢复真实注视点，也不会使原验证变为通过。结果页默认显示原始记录，可切换「参考校正」。原始回答、样本、验证及质量标签不变。

## 方法和使用范围

对每个展示试次，选择试次开始前已经完成、属于本景并匹配相同校准版本的**最近一轮漂移检查**。检查与画面显示的视口宽高必须一致；要求至少三个不同目标，各目标有效样本数至少为冻结的最少样本数且不少于三。剔除训练、稳定期和缺失预测。不从未来或其它校准版本借用检查；最近一次样本不足时不会退回更早的检查。

先对每个目标分别求 `median(targetX - predictionX)` 和 `median(targetY - predictionY)`，然后对目标偏移取等权中位数，得到 `dx, dy`（CSS px）。同一试次的有效观看样本应用 `x' = x + dx, y' = y + dy`，再按原始图像几何换算图内坐标。

不改变画作、时间、样本顺序，不缩放、不旋转、不插值。重新计算画内状态；越界点不夹回画内。原先在画外的有限预测经平移后可能进入画内，反之亦然，因此派生图的画内数量和轨迹分段可能与原图不同。null、暂停与无匹配依据的样本不绘入校正图；CSV 保留每个原始回调对应的行和未应用原因。

偏移超过视口对角线 25%，或在该参考检查上整体中位误差增大超过 1 px 时，不应用校正。以上是防止明显不合适平移的工程保护，不能保证自由观看的准确度。校正前后误差来自用于估计偏移的**同一轮检查**，是拟合诊断，不是独立验证。部分目标的误差可能增大；应查看每目标结果和原始图。

三点漂移检查不能识别完整二维形变，因此本版仅提供平移。不要根据轨迹外观任意拉伸、扭转或对齐人物。

## 本机导入与导出

首页「本地导入结果 ZIP / JSON」可读取本站单次原始导出。文件只在浏览器解析，不上传，也不写入或覆盖本机研究数据库；导入后对可视化参数的修改只在当前回看页面有效。关闭页面后重新导入即可。

一键 ZIP 始终保留原始 CSV/JSON/PNG。在存在参考校正时，追加 `gaze_samples_corrected.csv`、`correction.json` 和有依据画作的 `heatmap_*_corrected.png`、`scanpath_*_corrected.png`。没有依据的画作不会生成冒充校正的图。

`correction.json` 记录算法标识、每试次来源 run、校准和几何版本、目标样本数、偏移量、参考误差、不可用原因、实际图片尺寸及绘制参数。校正图显著标注「事后参考偏移校正 · 派生结果」。原始 `session.json` 加上保存的 plan 可重建校正 PNG；同浏览器字体环境下自动测试逐字节一致。

`applyCorrection()` 返回独立派生会话并设置 `coordinateSource: reference-corrected`，不修改输入。原始数据导出函数拒绝将此派生会话冒充原始记录；也拒绝重复校正。
