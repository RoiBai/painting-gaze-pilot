# 先导研究的暂定质量合格线

2026-11-16 应用户要求，为**新建会话**设定以下默认标准。它是这个 4–6 人形成性 pilot 的初始筛选规则，用于判断一次摄像头视线估计记录是否达到本项目的粗区域探索要求；不是通用眼动标准，也不是由文献验证过的精度保证。

## 默认条件：全部满足才通过

| 检查项 | 默认值 | 对应配置 |
| --- | --- | --- |
| 每个验证目标的有效预测样本数 | 至少 10 个 | `minSamplesPerTarget: 10` |
| 全部有效样本到各自目标的距离中位数 | 不超过 150 CSS px | `maxMedianErrorPx: 150` |
| 全部有效样本的距离 / 各自视口对角线的中位数 | 不超过 0.10，即 10% | `maxErrorDiagonalRatio: 0.10` |
| 每一个目标各自的距离中位数 | 均不超过 200 CSS px | `maxTargetMedianErrorPx: 200` |

这些规则同时用于独立验证和每景前的漂移检查。观看时长仍为每景 60 秒。

每个目标仍显示 2500 ms，切换后的前 700 ms 为稳定期，不参与判定。有效样本要求预测坐标为有限数，且不是训练记录或稳定期记录。null 保留在日志中，不补点，也不当作坐标 0。缺少误差、缺少目标或任一目标不足 10 个有效样本均为未通过。

最后一个条件用于防止“某个目标明显偏离，但被其它目标的大量较好样本掩盖”。总体中位数按实际有效回调合并计算，各目标可能贡献不同样本数；它不是各目标中位数的再次平均。

## 计算方法

对第 i 个有效验证样本，以 CSS 像素记录库预测 `(x_i, y_i)` 与当前目标 `(t_xi, t_yi)`：

```text
e_i = sqrt((x_i - t_xi)^2 + (y_i - t_yi)^2)
d_i = sqrt(viewportWidth_i^2 + viewportHeight_i^2)
整体像素误差 = median(e_i)
整体相对误差 = median(e_i / d_i)
目标 j 的误差 = median(e_i，其中目标为 j)
```

CSS px 不乘 devicePixelRatio。此项目没有测量屏幕物理尺寸和眼睛到屏幕的距离，因此不将这个像素误差换算成未经测量的视觉角度。

例如视口 1440 × 900 时，对角线约 1698 CSS px；10% 约为 170 px。150 px 和 10% 两条标准需要同时满足，所以该视口的整体有效上限为 150 px。视口 1024 × 768 的对角线为 1280 px，该视口的整体有效上限为 128 px。阈值边界采用“≤”；没有按个人表现自动放宽。

## 为什么采用这个初始数值

Yang 与 Krajbich 的 WebGazer 行为研究使用过 130、165、200 px 的验证半径，并结合落入半径内的样本比例和通过的验证点比例决定是否继续；他们也报告了边角区域偏差较大的现象。这说明需要独立验证、观察局部偏差，并根据任务所需空间分辨率设定标准。[原始研究：Webcam-based online eye-tracking for behavioral research](https://www.cambridge.org/core/journals/judgment-and-decision-making/article/webcambased-online-eyetracking-for-behavioral-research/B726E77B68A76577F9BC6BB8F1EBC6E4)

**本项目采用中位误差，论文采用命中比例，二者不等价。** 论文使用的库版本和处理过程也不等同于本项目固定的 WebGazer 3.5.3。本项目的 150 / 200 px、10% 和每目标 10 个样本是参照误差量级后作出的工程判断，不应写成该论文推荐或验证了这组标准。这里也不复用论文中按失败次数放宽标准的做法。

## 通过的含义与材料限制

通过表示该次独立检查符合以上冻结规则，不表示所有观看时刻都准确，也不表示任何一个落点都对应真实注视位置。应保留后续漂移检查、缺口、暂停、重校准和中断信息。

当前射箭裁图的宽高比约 3.5。如果它在页面中显示为 1440 px 宽，图像内容高度约为 411 px；150 px 已相当于图像高度的约 36%。因此，即使通过这条先导线，也不能据此声称能够可靠分开上下相邻人物、手指、弓箭细部或相邻细 AOI。当前 AOI 主要用于讲解定位；后续若要进行定量 AOI 归属比较，需结合实际显示几何、区域间距和各人验证误差重新评估材料与阈值。

Scan path 显示的是按时间排列的库输出估计样本。轨迹的可见顺序不等于已识别出精确注视点或扫视事件，不能由线条外观推断细微眼跳。

## 冻结、旧记录和失败处理

- 新会话开始前可在研究者设置或 JSON 中调整；开始时配置快照冻结并导出。正式采集前确定材料版本与标准，不能为了让某个参与者通过而事后更改阈值。
- 已保存会话继续使用其原有冻结标准。旧会话没有设置误差阈值的，不能用本次新默认值自动改判为合格，也不能自动改判为失败。
- 新增的 `maxTargetMedianErrorPx` 对旧配置为可选字段；缺失或为 null 表示该项未启用，其它原有条件照常计算。
- 未通过时显示具体原因：目标样本不足、整体像素误差超标、整体相对误差超标或某一目标误差超标。可重新校准；如仍继续流程，须保留相应低质量/流程试用标记。
- 样本回调率、画内样本比例与定位误差是不同指标。大量画内样本能够说明有估计记录，不能替代目标验证。

当前不设置“有效回调比例”硬门槛：现有验证日志还包含目标结束标记行，不能将这些行简单计入 null 回调分母并冒充有效率。先保留可审计的每目标样本数和定位误差，后续若增加覆盖率标准，应先明确区分真实回调与事件标记。
