## 内容依据与不确定性

历史描述依据故宫博物院《明人画明宣宗行乐图卷》：
<https://minghuaji.dpm.org.cn/paint/detail?id=9hv8wtoav5a5hyr0l7pmjc765dwesqti>

馆方把卷首两段解释为皇帝观看侍臣射箭、蹴鞠。配置仅采用这一层次的关系解释，以及直接可见的亭台、坐观人物、活动人物、园林空间。弓、箭靶与旗杆区域、动作和球可以作为理解依据；摄像头 AOI 始终是人物群或活动区域，不尝试测量单个小球、手指、眼睛是否被看到。

该馆方说明同时记载皇帝身份存在学术争议。因此使用传统题名《明宣宗行乐图》，解释卡采用“皇帝/坐观者”，不把具体帝号、作者身份、人物官职、比赛规则、队伍或胜负当成无争议事实或评分答案。空间联系属于画面观察，配置中与馆方的活动识别分开说明。

## 当前状态

`src/sceneMaterials.ts` 定义了两段图像、4–5 个粗 AOI、2 条关系、2 道前题、2 道平行后题、固定两张解释卡、研究者评分参考与访谈问题。配置示例为 `public/study.example.json`，默认配置在 `src/study.ts`。

当前 `mode = "preview"`、`placeholder = false`、`verified = false`。这表示已经装入真实绘画场景，可立即试用；不表示正式实验材料已经完成研究者审定。`validateConfig` 在正式研究模式拒绝任何 `verified !== true` 或 `placeholder !== false` 的材料。核查标记是研究者责任记录，程序不可能自动核验历史解释的真伪。

正式采集前请完成：

1. 在实际屏幕确认两张图片的清晰度和裁切范围；决定裁切是否符合本研究的场景范围。
2. 审核标题、来源、关系解释与身份争议处理；确认两段同一长卷适合研究问题。
3. 审核 AOI 是否过细；前后题是否平行且不依赖识别小物件；评分参考是否足以供研究者一致使用。
4. 冻结问题、解释卡、材料版本、120 秒或修订后的时长、AB/BA 规则。
5. 根据真实摄像头接通与校准测试设定验证阈值。默认未设误差阈值时只显示“待研究者判断”，不能视为已通过。
6. 将核查通过的材料设为 `verified: true`，保持 `placeholder: false`，切换 `mode: "research"`。每次开始将配置快照随会话保存；正式会话中不修改。

替换图片时把文件放在 `public/materials/`，配置使用 `/materials/name.jpg`，填写实际自然宽高。`imageX/Y` 对应当前场景裁图自身的像素坐标；不是完整长卷坐标。v2 只作原尺寸裁切，所以回到原卷时可分别加上配置 crop.rect 的 x/y；v1 的全卷坐标未知，不能这样转换。

## 验证误差计算

`src/validation.ts` 只使用对应 runId、当前 calibrationVersion 的独立验证或漂移记录，排除稳定期和训练标签，保留缺失目标的 n=0。

- 每目标 n：稳定期后、坐标有限的预测次数。
- 每目标误差：预测点与目标 CSS 像素位置之间欧氏距离的中位数。
- 整体误差：所有目标有效预测误差合并后的中位数（按实际样本计算，不是非空率）。
- 相对视口误差：每样本误差除以该样本记录的视口对角线，再取中位数。
- 任一目标样本不足，或设定的任一误差阈值超出，状态为 fail。
- 样本充足但两项误差标准均未设定时，状态为 judgment；不会自动 pass。

该整体指标按预测样本加权，采样较多的目标贡献较大；逐目标统计一并提供，研究者应同时查看。坐标采用 CSS 像素；devicePixelRatio 记录在几何快照中，不用于将 CSS 回调坐标重复乘倍。
