## 发现并修复

- 官方 end() 未停止摄像头 track：适配器显式释放流，并处理授权晚到。
- 官方 begin() 自动添加鼠标训练：训练限定在独立 iframe，删除监听器，校准外不训练。
- about:blank 触发官方 HTTP 检查：改成真实 localhost runtime.html。
- 重校准导致重复 trialId：每次实际曝光使用独立 attempt ID，保留中断前记录和重复曝光标记。
- 答题期间 resize：下一景前强制重校准。
- 图片 decode/呈现期间暂停：恢复后重新触发呈现步骤，避免卡在加载页。
- 初版网络分场景小图范围不全：按用户反馈更换为完整长卷的宽场景裁切，更新材料版本、AOI、定位说明及溯源。旧路径保留供旧预览记录复现。

执行过程中，本机沙箱曾拒绝测试服务器监听端口；允许本机测试后完成。一次并行测试的服务器被另一测试关闭，导致 ERR_CONNECTION_REFUSED；独立重跑后通过。相机拒绝测试更正了 CDP 权限名称及上下文，且移除自动授权测试标志后通过。这些环境/测试夹具问题没有被报告为真人眼动通过。
